Performed supervised classification on 5-year interval Landsat data from 1990 to 2015 and categorized each pixel into one of the five classes - water, urban land, open land, vegetation, wetland.

Created an accuracy assessment contingency matrix for classes and calculated overall accuracy of prediction and kappa coefficient.

Built a multiple linear regression model using the five developed classes and population to predict future urbanization as well as the land cover of different classes.
